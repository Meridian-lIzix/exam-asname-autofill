# 模拟训练批量答题助手

本地运行的 Chrome 扩展，用于 `exam.asname.cn` 知识练习：批量遍历题目、把每题的作答校正为正确答案，并把题干、选项、正确答案导出为复习资料。

## 安装

1. Chrome 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹
4. 打开 `https://exam.asname.cn/` 并登录，右下角出现「批量答题助手」面板

## 使用

1. 勾选要处理的场次（面板自动列出全部「知识练习」，已排除「每周测试」）
2. 请求间隔默认 120ms，实测服务端无限流，单场 260 题约 90 秒
3. 点「开始」；中途可「停止」，已处理结果会保留
4. 跑完刷新页面，每题都会显示为「回答正确」并高亮正确选项，可直接截图
5. 「导出 Markdown」得到带 ✅ 标注的复习资料，「导出 JSON」得到结构化题库

## 工作原理

服务端接口 `POST /api/assessment/assessmentmain` 只在题目被作答过之后才在 `select` 响应里返回 `r_answer`，且 `add` 可以重复覆盖同一题的作答。因此每题流程为：

```
select → 有 r_answer ?
  ├─ 否 → add("A") → select 读取 r_answer
  └─ 是 → 直接用
→ 作答 ≠ 正确答案 ? → add(正确答案)
```

已经正确的题不会重复提交，重复运行是幂等的。

题型：`type` 1=单选、2=多选、3=判断；多选答案为逗号分隔（如 `A,C,D`）。

登录凭证从 `sessionStorage` 中按 `eyJ` 前缀定位（站点的 key 名是混淆的），随页面刷新自动跟随，扩展不存储任何凭证。

## 数据

题库存在页面的 `localStorage`，键 `exam-autofill:vault`，按 `question_id` 去重累积，跨场次、跨多次运行合并。全部处理与存储在本地完成。

## 已知限制

- 已交卷的场次（接口返回「您已交卷」）无法读取题目，面板会记录并跳过该场次继续处理其余场次
